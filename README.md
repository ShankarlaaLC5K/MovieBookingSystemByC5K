 Movie Booking System
---------------------------------------------------------------------
A full-stack movie ticket booking App built using the MERN stack, were users can explore movies, browse theatres and showtimes, select seats, and manage their bookings. Admin can manage the movie booking platform.
---------------------------------------------------------------------

User Features
- User registration and login
- Secure authentication
- Browse and search movies
- Explore movie genres and release years
- View theatres, screens, and available showtimes
- Interactive seat selection
- View seat pricing and booking details
- Book movie tickets
- View booking confirmations and booking history
---------------------------------------------------------------------
 Admin Features
- Admin authentication and role-based access
- Manage movies and theatre information
- Manage screens and show schedules
- Manage bookings and seat availability
- View booking and platform information
- Access protected admin functionality
---------------------------------------------------------------------
 Movie Information
- Movie data integration using TMDB
- Movie posters and details
- Search and filtering functionality
---------------------------------------------------------------------
Payment Integration
- Payment integration support for movie bookings
- Razorpay integration for supported payment flows (Only Demo Test Payment Gateway has been worked)
